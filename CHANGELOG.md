# Changelog

## Unreleased

### Added

- Runnable CLI, in-memory HTTP and offline HTTP client examples using released
  PHP FastForward components.
- Integration and regression tests, PHP 8.3–8.5 CI, and a committed application
  dependency lock file.
- English setup, component mapping, extension, compatibility and migration guides.

### Changed

- Complete the existing application, router, action, JSON responder and console
  skeleton for PHP 8.3+.
- Preserve middleware across requests and encode all valid JSON payload values.
- Retain four identified historical entity and WebSocket class specimens outside
  the application autoloader.

### Removed

- The PHP 7.2/Slim 3 runtime, unconfigured external-service and cloud deployment
  scaffolding, empty class files, and automatic Git-hook replacement.
